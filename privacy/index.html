Политика конфиденциальности

Сайт wgl.su (Web Game Link) не собирает персональные данные пользователей через формы регистрации.

Мы не запрашиваем имя, телефон или паспортные данные для просмотра каталога.

Сайт может использовать localStorage только для сохранения настроек оформления (тема).

Может использоваться обезличенная веб-аналитика (например, Яндекс.Метрика) для понимания посещаемости.

Игры открываются на отдельных доменах (.su / .рф). Политика обработки данных на этих сайтах определяется соответствующими ресурсами.
